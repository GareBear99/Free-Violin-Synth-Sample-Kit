# Release Notes - v1.0.0

Initial public-ready package for **Free Violin Synth Samples**.

## Included

- 204 rendered one-shot WAVs (6 presets × 34 notes, G3–E6)
- 6 violin preset folders under `one_shots/`
- 4 preview WAVs under `previews/`
- Metadata JSON and CSV index under `metadata/`
- GitHub repo health files

## Planned next upgrades

- sampler mappings
- phrase pack expansion
- cinematic loop expansion
- darker articulations / swells / transitions
