# Contributing

Thanks for checking out Free Violin Synth Samples.

## Ways to contribute

- Improve documentation
- Add sampler mappings (SFZ / Decent Sampler / others)
- Improve metadata and tagging
- Submit preset-pack expansions derived from clearly licensed sources
- Add demo tracks or walkthrough material

## Please do not

- Upload third-party copyrighted violin libraries
- Add unclear-license sample content
- Replace existing pack audio with unverified source material

## Suggested workflow

1. Fork the repo
2. Create a branch
3. Make your changes
4. Open a pull request with a clear summary
