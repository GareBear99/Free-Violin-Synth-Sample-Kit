# AAA Violin Kit (derived from Instrudio violin)

This kit was rendered from the physical-model violin instrument found in the Instrudio package.

- https://github.com/GareBear99/Instrudio

## What's inside
- 6 violin preset folders
- 34 notes per preset
- Range: G3 to E6
- Format: 48 kHz / 16-bit / stereo WAV
- Total WAV files: 204

## Presets
- solo_cantabile
- warm_ensemble
- baroque_period
- sul_ponticello
- pizz_bright
- cinematic_legato

## Folder layout
- `one_shots/` = playable notes by preset
- `previews/` = quick audition files
- `metadata/` = instrument info

## Notes
This source package did not include a raw violin sample library. The violin is a modeled instrument, so this kit is a rendered sample pack built from that model.
